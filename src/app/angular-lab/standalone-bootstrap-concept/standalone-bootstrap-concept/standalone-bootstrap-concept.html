Ce qu’il faut comprendre

Une application standalone ne supprime pas l’injection de dépendances : elle déplace sa composition vers des APIs fonctionnelles et explicites.

  • bootstrapApplication démarre le composant racine.
  • Les fonctions provideX() configurent les services globaux.
  • Les composants déclarent directement leurs imports de template.

Quand l’utiliser ?

Nouveau projet

Choix par défaut pour une application Angular moderne.

Migration progressive

Convertir route par route sans réécriture totale.

Recommandation

Préfère les APIs standalone et provideX(). Conserve les NgModules uniquement lorsqu’un contexte existant le justifie.

À toi de jouer

  1. Ajoute une configuration via InjectionToken.
  2. Migre un petit AppModule.
  3. Vérifie que le provider est substituable en test.
